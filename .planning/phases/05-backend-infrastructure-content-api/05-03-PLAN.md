<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| Admin CLI -> Backend | Script sinh nội dung chỉ chạy local/CLI. |
| Backend -> Opencode API | Dữ liệu sinh ra từ LLM giao tiếp qua mạng internet. |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-02 | Spoofing | LLM Generation Script | medium | mitigate | Giữ script dưới dạng CLI tool `generate_content.py`, tuyệt đối không expose ra public REST API. |
| T-05-04 | Denial of Service | LLM Service | low | accept | Mặc dù gọi HTTPX ra ngoài có rủi ro timeout, nhưng đây là script chạy offline tay/cronjob nên crash không gây ảnh hưởng đến API chính. |
</threat_model>
