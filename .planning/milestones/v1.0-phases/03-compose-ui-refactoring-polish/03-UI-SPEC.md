## Design System

| Property | Value |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4dp | Icon gaps, inline padding between icon and label |
| sm | 8dp | Compact element spacing, list item internal gaps |
| md | 16dp | Default element spacing, card internal padding |
| lg | 24dp | Section padding, FeedbackBanner internal padding |
| xl | 32dp | Layout gaps between major sections |
| 2xl | 48dp | Major section breaks, top/bottom screen padding |
| 3xl | 64dp | Page-level spacing (reserved for full-bleed hero areas) |

Exceptions:
- Touch targets: minimum 48dp height for all interactive elements (Android accessibility guideline)
- 3D button bottom-border offset: 4dp (creates the raised/3D effect shadow)
- Progress bar height: 12dp (established pattern from existing `DuolingoProgressBar`)

## Typography

All sizes use `FontFamily.SansSerif`. Existing `Type.kt` defines the Material3 `Typography` object and will be the single source of truth.

| Role | Size | Weight | Line Height | Material3 Slot |
|------|------|--------|-------------|----------------|
| Body | 16sp | Normal (400) | 24sp (1.5) | `bodyLarge` |
| Label | 14sp | Normal (400) | 20sp (1.43) | `labelLarge` / `bodyMedium` |
| Heading | 20sp | Bold (700) | 28sp (1.4) | `titleLarge` |
| Display | 32sp | Bold (700) | 40sp (1.25) | `displayLarge` |

**Rules:**
- Max 2 weights per screen: Normal (400) + Bold (700). Use Bold (700) only for headings, emphasis, and button labels.
- Never use font size below 14sp for any user-visible text (accessibility).

## Interaction Contracts

### Quiz Answer Flow

1. User taps option → `Duo3DOptionCard` transitions to `selected` state (blue border, blue tint bg)
2. User taps "Kiểm tra" → Evaluate answer
3. **Correct:** Option transitions to `correct` (green), `DuoFeedbackBanner` slides up with "Chính xác!", haptic + success sound, `Duo3DButton` shows "TIẾP TỤC"
4. **Incorrect:** Option transitions to `incorrect` (red), correct answer highlights green, `DuoFeedbackBanner` slides up with "Chưa chính xác" + correct answer, shake animation (6dp horizontal, 300ms), `Duo3DButton` shows "ĐÃ HIỂU"

### 3D Button Press Animation

- Duration: 100ms down, 100ms up
- On press: translateY +4dp, bottom shadow height 0dp (button appears to push into surface)
- On release: translateY 0dp, bottom shadow height 4dp (button pops back up)

### Screen Transitions (Navigation Compose)

- Forward navigation: slide-in from right (300ms, `FastOutSlowInEasing`)
- Back navigation: slide-out to right (250ms, `FastOutSlowInEasing`)
- Quiz completion → Result: crossfade (400ms)

### Orientation Survival (UX-02)

- `SavedStateHandle` stores: `currentIndex: Int`, `sessionId: String`, `answeredQuestionIds: List<String>`
- On recreation: reload questions from DB using `sessionId`, jump to `currentIndex`
- Source: RESEARCH.md Open Question #1 recommendation

## UI Considerations

- **Duo3DButton Text Wrap**: Text is forced to a single line with `TextOverflow.Ellipsis`. Buttons will not wrap to multiple lines to maintain 3D height consistency.
- **DuoOptionCard Overflow**: Content inside the card wraps to multiple lines if it's long text. If the total height exceeds screen limits (many cards), the parent container must be scrollable.
- **DuoOptionCard Loading/Error**: Cards are only shown after quiz data is fully loaded. If image loading within a card fails, a fallback icon is displayed.
- **Progress Bar States**: Animates smoothly between values. If value is 0, empty bar with rounded corners. If 100%, full bar with rounded corners.
- **Dialog Backstop**: Confirmation dialog text must wrap cleanly without clipping on smaller screen sizes. (Backstop required)
- **Empty States**: If no lessons/words available, display the "Chưa có bài học nào" graphic and text from the Copywriting contract.
