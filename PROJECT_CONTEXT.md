# Dự án Vocab Master - Context\n\n## 1. Tổng quan dự án\n- **Tên dự án:** Vocab Master\n- **Loại ứng dụng:** Ứng dụng Android học từ vựng tiếng Anh (A1–C2), offline-first.\n- **Kiến trúc:** Jetpack Compose + MVVM + Clean Architecture + Hilt DI.\n- **Tính năng chính:** Áp dụng thuật toán FSRS v6 cho việc ôn tập từ vựng, gamification (XP, Streak, Badges), UX/UI học tập (tương tự Duolingo/Drops).\n\n## 2. Cấu trúc thư mục (Multi-module)\n- `gradle/`: Version Catalog (`libs.versions.toml`).\n- `domain/`: Module nghiệp vụ cốt lõi (Pure Kotlin). Chứa thuật toán FSRS, Models, Use Cases, Interfaces.\n- `data/`: Module lưu trữ (Room, DataStore, JSON assets). Chứa Entity, Dao, Repository Implementations.\n- `app/`: Module UI (Jetpack Compose). Chứa Application, MainActivity, ViewModels, UI Screens.\n\n## 3. Data Layer\n- **Room Database:**\n  - `VocabularyCardEntity`: Thẻ từ vựng và trạng thái FSRS.\n  - `ReviewLogEntity`: Lịch sử ôn tập.\n- **DataStore:** Lưu trữ settings, tiến độ, gamification.\n- **Repository Implementations:** `VocabularyRepositoryImpl`, `ReviewRepositoryImpl`, `SettingsRepositoryImpl`, `BackupRepositoryImpl`.\n\n## 4. Giai đoạn (Phase)\n- **Phase 0:** Project skeleton + Gradle setup.\n- **Phase 1:** FSRS v6 engine (port từ FSRS-Kotlin) + unit tests.\n- **Phase 2:** Full UI + Gamification (Onboarding → Home → Quiz/Flashcard → Result → Statistics → Settings).\n- **Phase 4:** JSON export/import backup.\n\n## 5. Các quyết định kỹ thuật quan trọng\n- Không dùng remote API, offline-first hoàn toàn.\n- Gamification mạnh mẽ với hệ thống điểm XP, Streak, Badge.\n- Giao diện người dùng sử dụng Jetpack Compose với Navigation State-based (không dùng Navigation Component của Jetpack).\n- Thuật toán FSRS v6 với 21 tham số mặc định.\n- Phân quyền kỹ càng cho các module: `domain` không phụ thuộc vào Android Framework.\n
